# P14 Release Polish

P14 is a visual and interaction polish pass on top of the merged P13 baseline.

- keeps desktop and laptop headers compact until the tablet breakpoint;
- makes workspace action controls sticky instead of the review journey strip;
- adds restrained strata color depth to the intake worksheet while preserving its editorial layout;
- keeps tablet and mobile fallbacks from consuming excessive viewport space.

No reasoning, authority, WebMCP, revision, or acceptance semantics change in this phase.
