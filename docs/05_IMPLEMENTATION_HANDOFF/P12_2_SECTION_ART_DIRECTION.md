# P12.2 — Section Art-Direction Pass

## Intent

P12.2 raises the P12 visual pass from a palette change into a section-level art direction system. Scam Museum is used only as a reference for editorial composition discipline: compact navigation, distinct section scenes, strong focal objects, asymmetric layouts, and responsive composition changes.

Groundline keeps its own visual language: reasoning field, strata, fault, provenance, and bedrock.

## Landing scenes

1. **Surface / hero** — editorial statement plus a static reasoning specimen that visualizes conclusion, claim, evidence, assumption, source, and a local fault.
2. **Method / strata** — large manifesto copy paired with a 2x2 grid explaining the four reasoning layers.
3. **Enter the reasoning field** — split editorial layout with field steps on the left and the existing real-decision/example entry actions on the right.

The existing button labels `Check my own decision` and `Try the example` remain unchanged.

## Workspace scenes

The P11 lifecycle stays frozen. P12.2 only changes visual composition:

- review journey becomes a compact sticky field header;
- decision framing reads as the conclusion layer;
- analysis reads as the claim layer;
- the live reasoning workspace descends through evidence, assumption, and source tones;
- revision and audit surfaces retain separate semantic undertones;
- the footer remains bedrock.

## Explicit non-goals

P12.2 does not change:

- workspace state;
- WebMCP tool behavior;
- triage semantics;
- structural review selection;
- revision lifecycle;
- human authority;
- accepted/superseded lineage;
- add/delete reasoning behavior.

The accepted lifecycle remains:

`Run analysis → Focus primary risk → Propose repair → Accept/Edit/Reject/Defer → next unresolved item`
